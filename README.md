## 为什么大家都盯着洛杉矶

说洛杉矶便宜VPS之前,先说说为什么是洛杉矶。

洛杉矶机房有几样东西别的地方给不了。第一是线路丰富,普通国际BGP、三网CMIN2、9929、CN2 GIA,基本上你能想到的中国方向优化线路,洛杉矶都有商家在跑。第二是原生IP,洛杉矶是美国本土IP,解锁各种流媒体、跑跨境电商、做外贸站都顺,不会出现IP归属地乱跳的问题。第三是价格,洛杉矶机房密度高,商家卷得厉害,年付十几美元的VPS一抓一大把。

当然,便宜不代表随便买。挑洛杉矶便宜VPS的时候,有几个坑要绕开:带宽是不是共享标称、流量是不是Fair Use(合理使用,不是真不限)、线路是不是真优化(有些标"优化"其实就是普通BGP)。这些下面选套餐的时候会逐一说。

## 线路怎么选,别买错了

看完上面一堆表格,你可能有点晕。我给你捋一下,按使用场景对号入座:

- **纯海外业务,不考虑国内访问**:选国际线路VPS($15/年起),最便宜,带宽大,流量多。买这个就别指望国内访问速度好。
- **国内用户为主,预算紧**:选9929+CMIN2优化线路($25/年起),三网都有优化,性价比最均衡。
- **国内用户为主,要大带宽**:选三网纯CMIN2高性能($35/年起),1Gbps带宽,适合跑量。
- **对IP属性有要求**:选双ISP($58/年起),适合特定业务场景。
- **预算充足,要顶配体验**:选Ryzen9 CN2 GIA($66/年起),线路天花板,适合对延迟和稳定性敏感的业务。

一句话总结:别为用不上的线路多花钱。如果你只是挂个Telegram Bot,国际线路$15/年就够了;如果你要做面向国内用户的网站,至少上9929+CMIN2那一档。
